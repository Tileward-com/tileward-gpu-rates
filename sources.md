# Where gpu-rates.json comes from

Retrieved 2026-10-10. This file is provenance: where each price was read, and what was decided when it was built. The prices are other
companies' list prices. They go stale, the calculator only ever uses them to fill an input the reader can overwrite, and the weekly agent
task (AGENT_TASK.md) re-reads them. The table below says exactly what was read, and from where.

**What a rate is.** On-demand, pay-as-you-go, Linux, US region, no spot / reserved / committed pricing. Multi-GPU shapes
are the instance price divided by the GPU count. Where several shapes carry the same card, the cheapest standard shape
with that exact memory size. The "basis" string in the JSON says which shape and region.

**Sources.**
- AWS (us-east-1): the AWS Pricing Calculator on-demand Linux file (b0.p.awsstatic.com), cross-checked against
  instances.vantage.sh. They agree on every row.
- Google Cloud (us-central1): cloud.google.com/products/compute/pricing/accelerator-optimized, "Price (USD)" column, read
  from raw HTML and the rendered page. The Cloud Billing Catalog API needs a key, so GCP rests on the page alone.
- Azure (eastus; H200 only in eastus2): prices.azure.com Retail Prices API, Linux Consumption rows only. GPU memory
  checked on Microsoft Learn.
- Oracle Cloud: Oracle's public price API (apexapps.oracle.com), shape-to-SKU mapping read from oracle.com/cloud/compute/pricing.
  The list has no region dimension; availability in Ashburn was not confirmed.
- CoreWeave: coreweave.com/pricing (raw HTML). The page says only "North America".
- Lambda: lambda.ai/pricing (raw HTML). The size tables are unlabeled; 8x/4x/2x/1x was inferred from table order and
  vCPU/RAM. The page names no region.

**Judgement calls made when this file was built (all easy to reverse in the JSON).**
- Google Cloud H200 is left out. Its page lists a price, but the docs require a reservation, Spot or Flex-start, so a
  plain on-demand rate would mislead.
- Lambda H100 is the 8-GPU SXM shape ($3.99 per GPU), not the cheaper single PCIe card ($3.29), so it compares like-for-like
  with the other providers' 8-GPU SXM shapes.
- Azure H100 is the documented ND96isr_H100_v5 ($98.32 an instance, $12.29 a GPU). Undocumented Linux variants in the API
  price at $88.488 an instance ($11.06 a GPU). Azure's NC40ads H100 is an NVL card with 94 GB and is excluded.
- Azure has no H200 price in eastus; eastus2 is used.
- AWS p5en.48xlarge is priced in us-east-1 in both sources; capacity was not confirmed.

**Independent spot-checks done after the research (2026-10-10).** Azure Retail Prices API, Standard_NC24ads_A100_v4 Linux
Consumption in eastus: 3.673 an hour (matches). Lambda pricing page: A100 SXM 80 GB 2.79, A100 SXM 40 GB 1.99, H100 SXM 80 GB (8x)
3.99, H100 PCIe 80 GB (1x) 3.29 (all match).

**Refreshing.** Re-read each source above, edit gpu-rates.json (one rate per line), and run `npm test`: the tests
check every rate names a listed card and provider, is a plausible number, and says what it is a price of. A card a provider
does not sell has no row, and the calculator shows that provider as "not offered" for it.
